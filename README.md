# Apple Website Clone

A static HTML/CSS clone of Apple’s iPhone landing page, built for layout practice and UI study. This project is a single-page experience with embedded styles and a collection of local and remote image assets.

## Features
- Multi-tier navigation bars similar to Apple’s product pages
- Hero sections for iPhone 15 Pro and iPhone 15
- iPhone comparison grid with feature highlights
- Accessories/iOS/Shop iPhone navigation tiles
- Uses Font Awesome via CDN and Apple-hosted imagery

## Tech Stack
- HTML5
- CSS3 (inline styles inside `index.htm`)
- Font Awesome (CDN)

## Getting Started
1. Clone the repository.
2. Open `index.htm` in your browser (no build step required).

Optional: use a local static server (e.g., VS Code Live Server) for easier development.

## Project Structure
- `index.htm` — main page with markup and styles
- `*.png`, `*.jpg`, `*.webp` — image assets used by the page
- `LICENSE` — MIT license
